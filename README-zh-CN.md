# DSH Review Format Guard

[English](README.md) · [安装与卸载](INSTALL.md) · [排查问题](docs/TROUBLESHOOTING.md) · [测试范围](COMPATIBILITY.md)

这个插件为 DeepSeek Harness（DSH）的原生自动审查补上一层返回格式检查和有限重试。

部分第三方中转服务会在 DSH 等待审批 JSON 时，返回普通文字、代码框、工具调用标记或不完整的 JSON，导致工具尚未执行，自动审查就报错。本插件针对这类格式问题提供兼容处理。

## 什么情况适合试用？

如果工具还没执行，就遇到下面这些错误，可以试试：

```text
Auto review of tool "working_directory" failed; its body was not executed
Unexpected token ... is not valid JSON
REVIEW_JSON_INVALID
Review response is not one complete JSON object
```

插件会检查完整返回，清理少量能明确识别的外围格式，并对不合格结果有限重试。合法拒绝通过完整流校验后直接交回 DSH，不为取得允许而重试；多次尝试仍不合格，就继续报错，不会拼凑一个“允许”。

## 安装

在 DSH 插件页面安装 **`dsh-review-format-guard@0.1.2`**。普通 `dsh web` 部署可以运行：

```sh
dsh plugin --profile web add dsh-review-format-guard@0.1.2 --ignore-scripts
```

桌面版自带命令、本地安装包与卸载步骤见[安装指南](INSTALL.md)。也可以从 [Releases](https://github.com/MintMilk777/dsh-review-format-guard/releases/tag/v0.1.2) 下载预构建的 `.tgz` 安装包。

按提示重启，确认插件已启用，会话仍处于“自动审查”模式。先试一句“只查看当前工作目录，不修改文件”。

## 它做了什么？

- 默认不按服务商或模型名称限制，只识别已核对的原生审查政策和请求结构。
- 保留原政策与完整待审数据。旧四栏目协议在数据后重申政策，多消息协议只在首条环境消息中重申，后续历史与末尾待审动作不变。
- 流中确认失败就及时结束并保留安全分类原因；成功结果仍要收完整条流并完整校验，只接受符合原生字段规则的结论。
- 可清理包住整个结论的 JSON 代码框、外围空白、开头的字节顺序标记，以及已核对的思考过程外围空白差异。不会从普通文字、思考过程或工具调用里寻找并截取“允许”。
- 默认最多尝试三次。每次总期限为 180 秒（`timeoutMs: 180000`），首个有效文字或思考内容最多等 120 秒（`firstContentTimeoutMs: 120000`），开始后连续 30 秒没有新有效内容就结束（`idleTimeoutMs: 30000`）。
- 用量统计（`usage`）、空白和重复快照不续期；新有效内容只重置空闲期限，总期限不续期。显式设置的 `timeoutMs`（包括旧值）仍生效。
- 快速连续返回时会定期让出执行机会，使取消、卸载和期限回调能及时运行。每次读取独立注册取消监听，读取结束即移除，避免在同一个待完成的 Promise 上不断堆积回调；取消不等待卡住的服务商读取或关闭操作。关闭过程的错误不覆盖主要原因。
- 三次尝试最坏约 9 分钟，再加重试前的退避等待，并非整次请求限时 180 秒。取消、认证失败、额度耗尽、输入过长或请求无效不重试；已知连接故障和部分临时服务错误有限重试，未知异常不盲目重试。资源超限最多共尝试两次，并受 `retries` 限制；缺失或冲突最多三次，合法拒绝一次结束。
- 相邻、同类型、同内容块编号的纯增量可以合并，不靠丢弃思考或额外元数据节省空间。原始事件上限从 8192 增至 65536，实际缓冲仍限 8192；保留事件的序列化体量（含快照）、有效内容、重放状态分别限 256 KiB，另有 4 MiB 保守内存预算，并非实际 JavaScript 堆内存上限。显式旧值仍生效，原始事件过多仍会失败。详见[流缓冲预算](docs/TECHNICAL.md#流缓冲预算)。

它通过标准插件接口挂载，不替换内置审查组件，也不改变服务地址或权限。

## 兼容范围

**v0.1.2：** 支持已识别的原生审查协议，包括 DSH `0.2.2-rc.1` 的多消息协议。当前与历史验证分别见[兼容说明](COMPATIBILITY.md)，其中包括最新实测的首内容超时。

旧版四栏目审查协议仍受支持。早期 v0.1.0 已在 DSH `0.2.1-rc.3` 和 `rc.5` 上核验；本次没有重新安装这些旧宿主。

安装不受 DSH 版本号范围限制。运行时不认识的审查政策或请求结构会原样交回 DSH，插件不会处理这些请求。

实测范围和官方源码依据见[兼容说明](COMPATIBILITY.md)。

## 使用中要知道的事

格式正确不代表判断正确。重试可能增加耗时和费用，也不能恢复持续不可用的服务。认证失败、合法拒绝、工具执行后报错，需要分别排查。

插件为失败尝试保留安全错误码和耗时的简短历史，后续成功时也会记录；最终失败附带该历史。不记录会话原文、凭据、模型回复或上游错误原文；DSH 与服务端的日志由它们各自管理。

不再需要时，在 DSH 中停用，或按[卸载步骤](INSTALL.md#卸载)移除。反馈问题请到 [Issues](https://github.com/MintMilk777/dsh-review-format-guard/issues)，并先去掉密钥和私人内容。
